# Solana批量生成钱包教程

{% hint style="success" %}
**批量生成钱包 | 生成指定数量的地址 | 安全免费**

#### **输入要生成的钱包数量，即可轻松获得钱包地址、助记词、私钥等信息，本地无网络实现，安全可靠，支持钱包信息一键导出**

[**立即体验>>>**](https://b.tools/solana/wallet/create)
{% endhint %}

## 如何使用创建钱包功能

1. 打开B.Tools[创建钱包](https://b.tools/solana/wallet/create)页面
2. 设置要生成的钱包地址数量
3. 点击立即生成，等待本地运行完成
4. 复制或导出钱包信息
5. 钱包生成完毕

{% hint style="danger" %}
**生成钱包完全在本地电脑执行，建议在生成钱包时断开网络**
{% endhint %}
