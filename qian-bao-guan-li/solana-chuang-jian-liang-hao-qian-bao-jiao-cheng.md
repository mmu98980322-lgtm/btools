# Solana创建靓号钱包教程

{% hint style="success" %}
**自定义生成 Solana 靓号钱包，支持指定数字与字母组合，轻松打造专属、易记的个性化链上地址。**

[**立即体验>>>**](https://b.tools/solana/wallet/vanity)
{% endhint %}

## 如何使用靓号钱包功能

1. 打开 B.Tools[靓号钱包](https://b.tools/solana/wallet/vanity)页面
2. 设置要生成的靓号的开头或结尾
3. 设置是否区分大小写、代币精度
4. 点击生成，等待本地运行完成
5. 复制或导出钱包信息
