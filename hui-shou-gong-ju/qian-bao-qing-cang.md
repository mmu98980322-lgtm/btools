# 钱包清仓

{% hint style="success" %}
**B.Tools｜钱包清仓｜一键卖出快速管理链上资产**

#### 支持快速处理钱包持有的代币资产，集中执行清仓操作，简化逐个代币卖出的繁琐流程，帮助用户高效管理钱包持仓，灵活调整资产配置。

[**立即体验>>>**](https://b.tools/solana/wallet-liquidate)
{% endhint %}

## 如何使用钱包清仓功能

1. 打开 B.Tools[钱包清仓](https://b.tools/solana/wallet-liquidate)页面
2. 导入钱包地址或通过钱包助手导入钱包，可点击查询余额
3. 选择归集目标地址（当前钱包/手动输入/钱包助手）
4. 输入Jito小费或选择普通
5. 再次确认归集钱包地址，点击开始清仓等待任务完成

{% hint style="warning" %}
**清仓说明**

**用地址表上方的钱包助手分组，或左侧导入按钮导入地址；列表仅本页有效。**

**查询后转移全部可转同质化 SPL（排除 NFT 与不可转账户）。开启回收空地址租金时，会在代币全部转移成功后自动再查空地址并退租到目标地址。**

**可单独开启是否转移 SOL，以及任务执行间隔与 Jito。**
{% endhint %}
