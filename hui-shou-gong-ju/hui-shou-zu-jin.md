# 回收租金

{% hint style="success" %}
**Solana 租金回收｜批量回收账户租金｜释放闲置资金**

#### 支持批量检查并回收 Solana 链上符合条件的账户租金，将可退还的租金汇总至指定钱包，释放闲置资金，简化账户清理流程。
{% endhint %}

## 如何使用回收租金功能

1. 打开 B.Tools[回收租金功能](https://b.tools/solana/sol-collect)页面
2. 支持单钱包查询、多钱包批量查询
3. 选择查询钱包地址（支持当前钱包/手动输入/钱包助手输入）
4. 点击查询空代币账户
5. 选择Jito小费，设置Gas费代付设置（暂未实现）
6. 点击一键领取等待任务完成

{% hint style="warning" %}
**使用 GAS 代付可能使相关钱包在链上被关联识别，请谨慎使用**
{% endhint %}

{% hint style="success" %}
**什么是SOL押金？**

• 收到新代币时会创建代币账户。

• 每个账户大约锁定 0.002 SOL 押金。

• 余额为 0 的账户可以关闭并领回押金。

• 回收所得会收取 10% 服务费。
{% endhint %}
