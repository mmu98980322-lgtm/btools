# 创作者奖励

{% hint style="success" %}
**B.Tools｜创作者奖励｜奖励管理收益高效追踪**

#### 便捷管理代币创作者奖励，支持奖励收益查询与相关数据追踪，帮助用户及时了解奖励分配情况，让链上收益管理更加清晰、高效。

[**立即体验>>>**](https://b.tools/solana/batch-creator-fees)
{% endhint %}

## 如何使用创作者奖励功能

1. 打开 B.Tools[创作者奖励功能](https://b.tools/solana/batch-creator-fees)页面
2. 支持单钱包查询、多钱包批量查询
3. 选择查询钱包地址（支持当前钱包/手动输入/钱包助手输入）
4. 查看账户列表信息
5. 查看领取设置并输入Jito小费
6. 点击一键领取等待任务完成

{% hint style="warning" %}
**安全提醒**

**私钥仅在本地浏览器用于签名，不会上传服务器。领取前请确认地址与可领金额，并预留足够 SOL 作为网络费与 Jito 小费。**
{% endhint %}

{% hint style="success" %}
**全网最低服务费：仅收取回收所得 SOL 的 1%。Bonk LaunchLab 创作者费用查询与领取即将支持。**
{% endhint %}
