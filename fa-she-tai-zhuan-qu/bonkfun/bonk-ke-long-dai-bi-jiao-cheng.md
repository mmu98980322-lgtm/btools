# BONK克隆代币教程

{% hint style="success" %}
**B.Tools｜BONK克隆代币教程｜快速自定义代币信息**

#### 零代码，输入代币地址即可快速复用相关代币信息并创建新代币，让发射准备更简单、更高效。

[**立即体验>>>**](https://b.tools/solana/bonkfun)
{% endhint %}

[BonkFun](https://bonk.fun/) 底层基于 [Raydium LaunchLab](https://raydium.io/launchpad/) ，功能相似且相互兼容。

开盘并买入流程与 Pump.fun 除页面UI不同但功能一样，请参考[Pump克隆代币教程](https://b.tools/solana/bonkfun)操作即可

> [**Pump克隆代币教程**](https://b.tools/solana/bonkfun)

{% hint style="warning" %}
账户余额至少需要预留 ≥ 0.12 SOL，用于支付服务费、GAS 和 Jito 小费等。

目前最多支持 8 个钱包地址买入，后续会持续拓展支持更多地址。
{% endhint %}

{% hint style="warning" %}
**在 Bonk.fun 创建代币并完成 DEV 买入；募集币种为 SOL。Jito 小费使用 SOL 支付。捆绑买入暂时停用。**
{% endhint %}
