# Pump开盘并迁移买入教程

{% hint style="success" %}
**B.Tools｜Pump开盘并迁移买入教程｜自动迁移、外盘买入联动**

#### **集成 Pump.fun 开盘买入与迁移交易策略，支持开盘阶段集中买入、自动迁移及外盘追加买入等操作，帮助用户灵活配置交易流程，高效衔接代币发射与后续交易管理。**

[**立即体验>>>**](https://b.tools/solana/pump)
{% endhint %}

## 如何使用**Pump开盘并迁移买入教程**功能

1. 打开B.Tools[Pump开盘并买入教程](https://b.tools/solana/pump)页面先连接钱包
2. 输入Token名称、符号<mark style="color:$danger;">（\*必填）</mark>
3. 填写描述、LOGO图片、社交媒体信息（非\*选填）
4. 选择募集币种SOL/USDC/股票，点击下一步
5. 设置创作者钱包信息，设定Jito 小&#x8D39;**（创作者钱包最少有0.1 SOL，Pump官方收取0.02 SOL）**
6. 设置内盘买入钱包信息
7. 设置外盘买入钱包信息
8. 点击“买入并买到发射”

{% hint style="warning" %}
创建代币过程受本地网络环境影响较大。如果持续失败，请尝试切换到更稳定的网络或开启VPN全局模式后再进行操作。
{% endhint %}
