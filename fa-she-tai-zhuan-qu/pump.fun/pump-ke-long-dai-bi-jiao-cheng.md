{% hint style="success" %}
**B.Tools｜Pump克隆代币教程｜快速复用代币数据｜一键创建 Pump 后缀代币**

## 如何使用**Pump克隆代币教程**功能

1. 打开B.Tools[Pump克隆代币](https://b.tools/solana/pump)页面先连接钱包
2. 粘贴需要复制的代币合约（可通过第三方行情网站获取代币合约信息）
3. 输入代币地址
4. 支持已克隆信息和权限配置修改，可支配度更高
5. 提交签名上链，生成新的代币元数据和代币合约，完成克隆代币

{% hint style="warning" %}
创建代币过程受本地网络环境影响较大。如果持续失败，请尝试切换到更稳定的网络或开启VPN全局模式后再进行操作。
{% endhint %}
