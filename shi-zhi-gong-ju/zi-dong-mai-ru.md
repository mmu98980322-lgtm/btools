# 自动买入

{% hint style="success" %}
<mark style="color:$success;">B.Tools｜自动买入｜智能交易策略｜高效执行</mark>

#### B.Tools支持自定义买入金额、触发条件与交易参数，自动执行预设买入策略，减少手动操作，帮助用户及时响应市场变化，让链上交易更加高效便捷。

[**立即体验>>>**](https://b.tools/solana/auto-control-buy)
{% endhint %}

## **如何使用自动买入**功能

1. 打开 B.Tools[自动买入](https://b.tools/solana/auto-control-buy)页面
2. 查找要进行买入的币种，可输入代币合约进行查找
3. 选择导入地址或通过钱包助手选择进行买入的钱包
4. 设置目标价格、下单方式、单笔最小金额及最小数量、单笔最大金额及最大数量、间隔时间
5. 设置Jito EVM 小费
6. 开始自动买入

{% hint style="warning" %}
**与市值交易相同的池子与余额逻辑，支持 Raydium AMM/CPMM、Launchpad、Pump；不支持 CLMM。导入地址后勾选并查询余额，再配置自动买入参数。**
{% endhint %}
