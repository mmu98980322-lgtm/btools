## 1. 页面总览

## 如何使用

1. 打开 [市值交易](https://b.tools/solana/market-cap)。
2. 在顶部选择链、路由和主币，输入代币合约，点「查询池子」。
3. 有多个池子时，核对总量、费率和单价后选一个。
4. 导入地址，勾选要参与的行，再「查询余额」。
5. 右侧切到「买入」或「卖出」，填数量或比例，点「一键买入」或「一键卖出」。
6. 成交状态在地址表的「状态/次数」里看，明细在「日志」和「活动」里看。

{% hint style="warning" %}
这一页是当场买卖，不是任务。关掉页面不会继续下一批。提交过程中可点「停止后续提交」；已经广播的交易仍会等待确认。
{% endhint %}

### 图文教程

**1. 打开页面**

宽屏是左表右栏：

* **上：代币与流动池。** 链、路由、主币、代币合约、「查询池子」。查到后显示代币信息。
* **左：地址与余额。** 导入、勾选、查询余额。勾选后，右侧「已选·持有」只统计这些地址。
* **右：买入 / 卖出。** 两个页签。小屏时买卖收在底部，点开后再填。

<figure><img src="../.gitbook/assets/image (180).png" alt=""><figcaption></figcaption></figure>

**2. 和策略页、工作台的差别**

* 市值交易：勾选地址，马上买或卖。
* 策略公开页（自动买入、防夹刷量等）：配的是任务，点开始后按条件自己跑。
* [VIP 工作台](https://b.tools/solana/vip)：按项目编排这些任务。工作台右侧的「市值交易」和本页是同一套买卖，对象换成该项目里勾选的钱包。

## 2. 查询代币和池子

## 如何使用

1. 顶栏切到要操作的链。Solana 市值页地址是 `/solana/market-cap`。
2. 选择路由。Solana 常见为自动、Raydium、Pump、Bonk。
3. 选择主币（池子的支付侧，例如 SOL）。
4. 在「选择代币」里搜索符号，或粘贴合约地址。
5. 点「查询池子」。
6. 查出多个池子时，在列表里选一个。选中后状态变为「池子已就绪」，代币信息加载到页面上。

{% hint style="warning" %}
未选择池子时不能下单。Raydium CLMM 池可以在本页查询和尝试成交；当前价格落在流动性区间外，或区间内流动性不足时，会买不成或卖不成。自动买入等策略页不支持 CLMM。
{% endhint %}

### 图文教程

**1. 查询**

* 合约以查询结果为准。搜不到时，换路由或确认这条合约属于当前链。
* 池子行上能看到总量、费率、单价。点复制可复制池子 ID。
* 个人备注只存在本机，不影响链上。

<figure><img src="../.gitbook/assets/image (181).png" alt=""><figcaption></figcaption></figure>

**2. 换池或换币**

再查一次并重新选择即可。已导入的地址列表还在，余额要重新查询后才对应当前代币。

## 3. 导入地址并查询余额

## 如何使用

1. 点「钱包助手」选择已有分组，或点「导入地址」粘贴私钥。
2. 需要在现有列表上加地址时，先勾选「追加」。未勾选时，这次导入会替换当前列表，并自动去掉重复地址。
3. 用「显示分组」看全部或某一个组。
4. 勾选要买卖的行。表头可全选。右侧会显示「已选 N 个地址」。
5. 点「查询已选」或「查询全部」。查完后，SOL、主币、代币余额和占比会出现在对应列。
6. 右键一行：复制地址、复制私钥，或清空列表。

{% hint style="warning" %}
下单用的是这些地址在钱包助手里的私钥。助手若处于锁定，会先弹出密码解锁，不必离开本页。
{% endhint %}

### 图文教程

**1. 从钱包助手导入**

分组要先在 [钱包助手](https://btoolsapp.gitbook.io/b.tools/qian-bao-guan-li/solana-qian-bao-zhu-shou-jiao-cheng) 里建好。本页只引用分组，不会因为换池就把助手里的地址删掉。

**2. 余额怎么更新**

* 「查询已选」只查勾选行；「查询全部」查表里所有地址。
* 点余额旁的设置可改更新方式：
  * **WSS 监听**：查完后由节点推送变化。范围可选「全部已查」或「仅勾选」，并可限制监听数量。地址很多时用付费节点更稳。
  * **手动请求**：只有再点查询才更新。

## 4. 买入

## 如何使用

1. 确认池子已就绪，且已勾选地址、查过余额。
2. 右侧打开「买入」。
3. 选择下单方式：
   * **按数量**：每个勾选地址各花填写的主币数量。快捷档有 `0.01`、`0.1`、`0.5`、`1`，也可手填。
   * **按比例**：每个地址按自己的主币余额乘这个百分比。常用档为 `10`、`25`、`50`、`75`、`100`。
4. 填写 Jito 小费和滑点。滑点常用档为 `5`、`10`、`20`、`50`、`100`，也可手填。小费越高越容易先进块，滑点越大越容易成交。
5. 需要把多个钱包打进同一笔交易时，勾选「自动合并」。
6. 点「一键买入」。未勾选地址时按钮不可用。

{% hint style="warning" %}
「总数」只显示这次的合计，不改变每个钱包的数量。10 个地址各买 `0.0005`，勾选后合计显示 `0.005`，每个地址仍买 `0.0005`。按比例时，合计是各地址「自己的余额 × 比例」相加。
{% endhint %}

{% hint style="warning" %}
自动合并后，多个钱包会出现在同一笔交易里，容易被看成同一主体。Pump 内盘每笔大约合并 3 个钱包，Pump AMM 或 Raydium 大约 2 个；Raydium 合并失败时会自动拆开再发。
{% endhint %}

### 图文教程

**1. 核对再提交**

勾选「总数」后，买入卡会写出：

* 按数量：「每个地址各买入 …」，以及预计合计。
* 按比例：「每个地址按余额的百分之几买入」。

提交中按钮变为「提交中…」，可点「停止后续提交」。地址行状态会在空闲、交易中、确认中、已确认、失败之间变化，并累计次数。

## 5. 卖出

## 如何使用

1. 勾选持有该代币的地址，并已查询代币余额。
2. 右侧打开「卖出」。
3. 选择下单方式：
   * **按持仓比例**：每个地址卖掉自己持仓的百分之几。快捷档为 `10`、`25`、`50`、`75`、`100`。`100` 即该地址全部卖出。
   * **按数量**：每个地址卖掉填写的代币数量。余额不够的地址会失败。
4. 小费、滑点、自动合并、「总数」与买入相同。卖出侧的「总数」同样只做合计显示。
5. 点「一键卖出」。

## 6. 活动、日志和 K 线

## 如何使用

1. 在地址区打开「显示块设置」，可显示或收起「代币信息」「活动信息」。
2. 点「活动」看该代币的成交。可「只看我的」（钱包助手和本次导入的地址），也可刷新。
3. 点「日志」看本页买卖记录。还没操作时为空。
4. 点「K线」看价格或市值。周期有 1 分钟、5 分钟、15 分钟、1 小时、4 小时、1 天。可改为独立窗口。未查询代币时不能打开。

## 其它链

操作顺序与 Solana 相同：查池、导入地址、勾选、查询余额、买入或卖出。

链上选项会随路由变化：

* **BNB Chain 等 EVM：** 右侧可能出现 Gas 加价、线程数。勾选合并交易后，多个钱包会进同一笔打包；合并后同样容易被关联。部分路由在合并之外还有「快速模式」，会跳过模拟直接发送。
* **需要授权的代币：** 地址表会多出买入授权、卖出授权。第一次卖出或用报价币买入时，会先发出授权，再买卖。
* **Four、Flap 等曲线盘：** 先按该协议查询。已毕业的代币会改走外盘池；还在曲线上时按页面提示的支付币下单，每个钱包仍要留一点原生币付 Gas。
