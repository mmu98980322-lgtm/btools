#### B.Tools支持 Solana Jito 捆绑交易与同区块买卖策略配置，帮助用户灵活管理交易执行流程，优化滑点与交易成本控制，提升链上操作效率。

## **如何使用防夹刷量（无损）**&#x529F;能

1. 打开 B.Tools[防夹刷量](https://b.tools/solana/anti-clip)页面
2. 查找要进行刷量的币种，可输入代币合约进行查找
3. 选择导入地址或通过钱包助手选择进行刷量的钱包
4. 设置每笔交易金额
5. 设置Jito EVM 小费
6. 开始刷量

{% hint style="warning" %}
**与市值交易相同的池子与地址逻辑；右侧配置刷量参数，导入地址并查询余额后操作；不支持 CLMM。**
{% endhint %}

**1.打开 B.Tools**[**防夹刷量**](https://b.tools/solana/anti-clip)**页面**

<figure><img src="../.gitbook/assets/image (200).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image (201).png" alt=""><figcaption></figcaption></figure>

**3.选择导入地址或通过钱包助手选择进行刷量的钱包**

* **钱包刷量**每次只能刷量 1 次，每次签名后进行刷量
* **私钥刷量**支持选择刷量次数，单次可以运行刷量 1-20 次

<figure><img src="../.gitbook/assets/image (202).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
**独立页不使用任务名称。左侧选择钱包组与右侧「钱包助手」为同一入口；执行顺序决定下单先后。**
{% endhint %}

**4.设置每笔交易金额**

* 同笔先买后卖刷量；勾选参与钱包

<figure><img src="../.gitbook/assets/image (203).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
**时长/累计/次数，谁先到谁停。填 0 = 不限。**
{% endhint %}

**5.设置Jito EVM 小费**

* Jito MEV 防夹模式为您的交易分配专用“赛道”，基于 Solana 的技术，确保每个区块有三分之一的空间专用于 Jito 的操作。
* 通过固定位置的捆绑包，Jito MEV 功能可以提高上链的速度和成功率
* 可选择支付给矿工的“贿赂”费用，提高交易的优先级，费用越高，交易上链速度越快

<figure><img src="../.gitbook/assets/image (204).png" alt=""><figcaption></figcaption></figure>

**6.开始刷量**

* 开始后可查看刷量日志
