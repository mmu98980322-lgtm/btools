# 中继转账

{% hint style="success" %}
**B.Tools｜中继转账工具 | 多钱包资金调度保障用户隐私**

#### 中转转账功能，旨在为用户提供一种更加隐蔽和安全的转账方式。通过多次中转，用户可以有效隐藏转账路径，从而提高资金转移的隐私性和安全性。

[**立即体验>>>**](https://b.tools/solana/relay-transfer)
{% endhint %}

## 如何使用中继转账功能

1. 打开B.Tools[中继转账](https://b.tools/solana/relay-transfer)页面
2. 连接钱包、切换主链、选择代币、选择配对模式（一转N、N转N）
3. 输入发送方地址、接收方地址，可选择导入地址/钱包助手
4. 设置发送数量，可选择全部数量/百分比数量/随机数量/固定数量
5. 选择中转次数，获取中转数据才能进行下一步（直连模式无需生成中转钱包，可直接进入下一步）
6. 确认转账信息，选择小费模式（是否使用GAS代付设置）
7. 确认无误后点击发送上链等待转账完成
