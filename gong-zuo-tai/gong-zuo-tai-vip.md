## 1. 工作台总览

1. 打开 [工作台](https://b.tools/solana/vip)，连接钱包。未连接时只能看到连接入口。
2. 左侧「项目代币」里新增项目，或点「发射平台」开盘后自动落入项目。
3. 点选一个项目。未选中时，中间区域不能操作。
4. 在该项目上绑定钱包组。
5. 中间看价格、持仓和任务；宽屏右侧是「市值交易」，用来对勾选钱包当场买或卖。
6. 任务的启停和结果在「任务台」和底部「执行日志」里看。

{% hint style="warning" %}
刷新页面后，正在运行的任务会停止，需要在任务台重新点「启动」。
{% endhint %}

### 图文教程

**1. 打开工作台并连接钱包**

<figure><img src="../.gitbook/assets/image (139).png" alt=""><figcaption></figcaption></figure>

**2. 看清页面分区**

宽屏从左到右是三块：

* **左：项目代币。** 列表、平台筛选（全部 / Pump / Bonk / 其他）、发射平台、新增。选中的项目卡片里管理绑定的钱包组。
* **中：当前项目。** 上方是价格、持仓、盈亏和任务状态；接着是代币信息，以及「归集全部」「卖出全部」。再往下是「钱包组持仓」和「任务台」，中间可以拖动调整高度。最底是「执行日志」。
* **右：市值交易。** 仅宽屏显示，可收起。买卖对象是持仓表里勾选的钱包。

小屏改为上下排列：项目在上，持仓和任务在下。

<figure><img src="../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>

**3. 和公开市值页的关系**

公开页是单页开跑某一个策略。工作台是按项目把这些策略收在一起。两边填的参数、跑起来的规则相同。

已开通工作台后，在公开策略页点开始，这条任务会出现在对应项目的任务台里，可以在这里看进度、暂停或删除。关掉公开页，任务还在。

策略卡片上的外链图标只是打开公开页，方便大屏查看。任务仍在工作台创建和运行。

## 2. 建项目并绑定钱包组

{% hint style="success" %}
先有项目，再绑钱包组。任务只会使用当前项目已绑定的分组。
{% endhint %}

1. 在左侧点「新增」。
2. 输入代币合约并查询。确认名称、符号和交易池。
3. 填写项目名称（只用于列表显示，合约以查询结果为准），点「确认并进入项目」。
4. 若还没有命名分组，在项目卡片里点「打开助手并创建分组」，到 [钱包助手](https://btoolsapp.gitbook.io/b.tools/qian-bao-guan-li/solana-qian-bao-zhu-shou-jiao-cheng) 建好分组后再回来。
5. 点「绑定」，从钱包助手已有分组里选择。绑定的是分组引用。
6. 需要改地址时，点该组的「管理」，在助手里改。解绑或删除项目不会删除助手里的地址。

{% hint style="warning" %}
项目上有正在执行的任务时，不能保存对交易池的修改。先暂停或结束任务，再编辑项目。
{% endhint %}

### 图文教程

**1. 新增项目**

* 查询方式与市值页相同。查到代币后才能进入项目。
* 同一条链上，同一个代币只能有一个项目。
* 编辑时可改项目名称、支付代币和交易池。已有任务和已绑定的钱包会保留。

<figure><img src="../.gitbook/assets/image (142).png" alt=""><figcaption></figcaption></figure>

**2. 绑定钱包组**

* 选中项目后，卡片内出现「绑定钱包」。
* 「绑定」打开助手里的命名分组。还没有命名分组时，可以临时绑定未分组地址；未分组后续不好区分，建议先建分组。
* 勾选已绑定的组，再点「解绑」，只解除和本项目的关联。
* 每个分组旁的数字是该组钱包数量。

<figure><img src="../.gitbook/assets/image (143).png" alt=""><figcaption></figcaption></figure>

**3. 删除项目**

删除会终止该项目下的全部任务，并解绑钱包组。钱包助手里的分组和地址还在。此操作不能撤销。

## 3. 持仓与快捷买卖

1. 选中项目，并确认已经绑定钱包组。
2. 在「钱包组持仓」点「查询」，或点列表头分别查 Gas、主币、项目代币。余额不会自动刷新。
3. 用「显示分组」看全部，或只看某一个组。可用名称、地址片段缩小范围。
4. 勾选要操作的钱包。补资金、归集、卖出：已勾选就直接用这些钱包；没勾选会再弹框，让你选本项目的分组。
5. 宽屏展开右侧「市值交易」，对已勾选的钱包当场买入或卖出。成交记在底部执行日志。

{% hint style="warning" %}
市值交易里的「总数」只把数量加成合计显示。10 个钱包各买 `0.0005`，勾选后合计显示 `0.005`，每个钱包仍买 `0.0005`。
{% endhint %}

### 图文教程

**1. 看持仓和汇总**

选中项目后，持仓表上方有一块汇总：

* **当前价格**：按池子价折算。
* **钱包总持仓**：来自最近一次查代币，包含各来源的余额。
* **净成本均价、总盈亏**：只统计工作台任务里的买入和卖出，保存在本机浏览器。点「重置成本」会清空这笔账，不影响钱包和已查出的持仓。
* **任务状态**：运行中、等待、暂停、取消的数量。

<figure><img src="../.gitbook/assets/image (144).png" alt=""><figcaption></figcaption></figure>

**2. 快捷买卖**

* 先在持仓表勾选钱包。未勾选时，右侧不能提交。
* 买入、卖出的数量方式与 [市值交易](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/shi-zhi-jiao-yi) 相同：按数量或按比例，并设置滑点和小费。
* 窄屏没有这一栏，当场买卖请打开公开市值页。

<figure><img src="../.gitbook/assets/image (145).png" alt=""><figcaption></figcaption></figure>

## 4. 新建并运行任务

1. 选中项目，并已绑定要参与的钱包组。
2. 在任务台点策略快捷按钮，或点「新建策略」。常用策略可自定义，最多 6 个，其余在「更多」里。
3. 在弹窗顶部选定策略。外链图标只打开对应公开页。
4. 按分区填写：**任务 → 目标 → 下单 → 上限 → 链上**。
5. 点「创建任务」。任务先出现在任务台，状态为「等待中」。
6. 在该任务上点「启动」。之后可以「暂停」「编辑」或「删除」。删除正在运行的任务会立刻终止。
7. 到底部「执行日志」查看。可按全部、任务、交易、补给、钱包、系统、详细日志筛选。

{% hint style="warning" %}
上限里的目标价、运行时长、累计金额、次数：填了才生效，谁先到谁停。填 `0` 或留空表示这一项不限。运行时长单位是分钟，交易间隔单位是秒。
{% endhint %}

{% hint style="warning" %}
影线冲击没有「创建任务」。在表单里点「开始」会创建并立刻执行。其余策略都要再在任务台点「启动」。
{% endhint %}

### 图文教程

**1. 从任务台进入**

任务台标题下是策略快捷。没有任务时，点上方快捷策略即可创建。

<figure><img src="../.gitbook/assets/image (146).png" alt=""><figcaption></figcaption></figure>

**2. 任务**

* **任务名称**：列表里显示用。
* **钱包组**：可多选。勾选顺序就是「正序」时的组顺序。
* **执行顺序**：随机顺序、正序、倒序。决定组内钱包谁先下单。

新地址买入这一区只要任务名。买入地址在生成转账计划时写入钱包助手，并绑定到本项目。

<figure><img src="../.gitbook/assets/image (147).png" alt=""><figcaption></figcaption></figure>

**3. 目标、下单**

这两区决定何时动手、每一笔怎么下。字段与该策略的公开页相同，见下一节的文档链接。

常见下单选项：

* 按数量，或按比例（含按余额比例）。
* 固定金额 / 固定比例，或随机区间。
* 交易间隔：固定秒数，或最小到最大的随机秒数。

**4. 上限**

默认收起。用来停任务，不决定每一笔下多少。

* 单地址累计、单地址次数、单笔上限、累计最大、总次数。
* 运行时长（分钟），旁边是已运行时间。
* 已累计、已买次数一类是只读，用来对照上限。

**5. 链上**

默认收起。一般保持默认即可。

* 小费、滑点：小费越高越容易先进块，滑点越大越容易成交。
* 代付钱包、同时笔数、自动合并、每钱包最低保留。

**6. 在任务台看状态**

状态有：等待中、运行中、暂停、完成、已取消。

任务行上可以启动、暂停、编辑、删除。勾选多条后可以一起删除。

## 5. 各策略

在工作台里选择策略后，参数与对应公开页一致。公开页用地址表勾钱包；工作台改为勾选本项目的钱包组。

| 工作台名称 | 干什么                                   | 参数见                                                                                               |
| ----- | ------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 自动买入  | 指定钱包组分批买入                             | [自动买入](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/zi-dong-mai-ru)                       |
| 自动卖出  | 按持仓比例或数量分批卖出                          | [自动卖出](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/zi-dong-mai-chu)                      |
| 防夹刷量  | 同一笔里先买后卖，用来做成交                        | [防夹刷量](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/fang-jia-shua-liang)                  |
| 低吸高抛  | 跌到触发价买入，涨到触发价卖出                       | [低吸高抛](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/di-xi-gao-pao)                        |
| 内盘封顶  | 内盘剩余量低于设定时买入；可选发射到外盘后卖出               | [内盘封顶](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/nei-pan-feng-ding)                    |
| 托底护盘  | 跌破设定价格或市值时买入                          | [托底护盘](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/tuo-di-hu-pan)                        |
| 市值台阶  | 市值或价格到某一档后，用该档钱包组买入或卖出。公开文档标题为「阶梯出货」  | [阶梯出货](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/jie-ti-chu-huo)                       |
| 大单防守  | 池子主币储备突然增加，或短时涨幅达到设定时，按持仓比例卖出，或只记录不卖出 | [大单防守](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/da-dan-fang-shou)                     |
| 新地址买入 | 用主钱包按计划把资金分到新地址再买入                    | [新地址买入](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/xin-di-zhi-mai-ru)                   |
| 影线冲击  | 立刻向下或向上冲击，形成影线；可选冲击后再回补或回踩            | [影线冲击（开发中）](https://btoolsapp.gitbook.io/b.tools/shi-zhi-gong-ju/ying-xian-chong-ji-kai-fa-zhong) |

工作台里需要额外知道的只有两处：

* **新地址买入**：创建前要能生成转账计划，并确认来源钱包余额够用。创建后，新地址分组会出现在本项目的绑定里。
* **影线冲击**：点「开始」即创建并执行。编辑已有任务时，底部是「保存修改」。

## 6. 补资金、归集与卖出

这三件事都从当前项目出发。持仓表上的按钮作用于勾选钱包或再选的分组；代币信息上的「归集全部」「卖出全部」作用于本项目已绑定的范围。

### 6.1 补资金

1. 在持仓表勾选钱包，或先不勾，点「补资金」后再选分组。
2. 确认补给目标：哪些组、多少个钱包。
3. 选择补给钱包：当前钱包、填写私钥，或从钱包助手选择。
4. 按需打开「补 Gas」「补主币」。可填子钱包最低保留、单次最大补给。主币和 Gas 是同一种币时，只开补主币。
5. 多地址直补容易关联时，可启用中继转账，并选择中转次数。
6. 确认后执行。结果在执行日志的「补给」里。

<figure><img src="../.gitbook/assets/image (148).png" alt=""><figcaption></figcaption></figure>

### 6.2 归集

1. 从持仓表点「归集」（勾选钱包或再选分组），或从代币信息点「归集全部」（已绑定的分组）。
2. 选择归集资产：主币，或本项目代币。
3. 可设置每个钱包保留多少、低于多少不归集。归集主币时，每个地址会预留一笔网络费。
4. 收款地址填两遍。两次一致后再确认。
5. 最后确认框核对的是收款地址。已广播的交易不能撤销。

{% hint style="warning" %}
归集收款地址不是当前连接的钱包，除非你明确选用了「当前钱包」。地址填错无法找回。
{% endhint %}

<figure><img src="../.gitbook/assets/image (149).png" alt=""><figcaption></figcaption></figure>

### 6.3 卖出

持仓表上的「卖出」，和代币信息上的「卖出全部」，不是同一个动作。

**卖出（持仓表）**

1. 勾选钱包后点「卖出」：只卖这些钱包里的本项目代币，比例为 100%。不终止正在运行的任务。
2. 没有勾选时，先弹框选择本项目的分组，再卖出。

**卖出全部（代币信息）**

1. 点代币信息右侧「卖出全部」。
2. 确认后，先终止本项目正在运行的任务，再把绑定范围内的本项目代币卖出。
3. 按钮旁的齿轮是「卖出全部设置」，用来设这笔卖出的 Jito 小费。卖出不设最小获得，并按市值交易的规则合并钱包。

<figure><img src="../.gitbook/assets/image (150).png" alt=""><figcaption></figcaption></figure>

## 7. 工作台开盘

{% hint style="success" %}
在工作台里打开发射平台，发完的代币会自动成为当前项目，不用再手动新增。
{% endhint %}

1. 在左侧点「发射平台」。若当前筛选是 Pump 或 Bonk，会直接打开对应平台。
2. 在弹窗里切换 Pump 或 Bonk。表单与发射台公开页相同。
3. 按该平台的开盘教程填名称、符号、描述和图片，确认后发送。
4. 成功后关闭弹窗，新币已经在左侧项目列表里，并处于选中状态。
5. 接着绑定钱包组，再创建任务。

平台筛选条可以自定义：勾选要出现的发射平台，并用箭头调整顺序。「全部」始终显示。
